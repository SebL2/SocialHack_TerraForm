# TF2 overlay fonts

TF2 Build and TF2 Secondary, from the TF2 extended fonts project:
https://github.com/jakadak/TF2-extended-fonts

The source README attributes the fonts to Andrea Wicklund / Valve Corporation and describes non-commercial use. Retain this attribution. This project is a non-profit educational prototype.

These fonts are scoped to the game overlay. Tutorial cards, dialogs, chapter previews, and entry screens retain their original typefaces.


Valve Occult SemiBold is retained from a typography experiment; the active interface uses TF2 Build and TF2 Secondary. Source: https://deadlock.wiki/File:ValveOccult-SemiBold.woff2 (font asset: https://cdn.deadlock.wiki/ValveOccult-SemiBold.woff2). Valve font, mirrored by the Deadlock Wiki. Original TF2 fonts are retained for reverting the experiment.
